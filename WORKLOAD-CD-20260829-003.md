## Purpose

Study 003 tests whether fresh model reconstruction and governed state retrieval can satisfy the same explicitly selected state task before their economics are compared.

Study 003 corrects the representation-selection ambiguity discovered in Study 002.

## Study 002 Finding Being Corrected

Study 002 used an independently frozen public-authority package, but that package exposed multiple plausible public representations of Robbie George and the Biography Plate.

The P1 task did not explicitly identify a JSON-LD block or the Biography Plate fragment.

Observation CD-002-P1-0001 therefore selected a different public ProfilePage representation.

The frozen Study 002 Quality Gate correctly failed that observation.

A later frozen diagnostic found:

- 14 total failed fields
- 12 of 14 failed fields were nevertheless grounded in the frozen public-authority package
- 6 fields exhibited direct public multi-representation conflicts
- the P1 task explicitly selected neither a JSON-LD path nor the Biography Plate fragment

Study 002 remains closed and unchanged.

## Representation-Selection Rule

P1 is not asked to infer which public representation is canonical for this benchmark.

The benchmark explicitly identifies the selected public JSON-LD surface before measurement.

P1 must reconstruct that selected state surface from independently public evidence.

A different public ProfilePage, WebPage, Person, FAQPage, CreativeWork, or other JSON-LD node does not satisfy the task merely because it is also publicly valid.

## Path 1 — Fresh Reconstruction

P1 uses a fresh model request.

P1 receives:

1. the frozen neutral task specification;

- post-measurement corrections.

P1 must reconstruct the selected public state using the supplied independent evidence.

## Transport Normalization

The governed retrieval layer may rewrite transport-specific identity fields such as @id.

Any allowed transport normalization must be declared before measurement.

Semantic or representational differences not declared before measurement cannot be waived after observing results.

## Governed-Only Fields

Fields that exist only because of governed retrieval, source-version metadata, payment wrappers, retrieval metadata, or protected state normalization may be recorded diagnostically.

They must not be used to make P1 fail unless they are independently recoverable from the explicitly selected public state surface and were declared part of the Quality Gate before measurement.

## Economic Rule

No Compression Dividend is computed unless quality equivalence is established first.

For a successful quality-equivalent pair:

P1 requester cost = measured fresh model cost

P2 requester cost = measured provider-cache cost, if available

P3 requester cost = measured governed retrieval payment plus any required residual compute or verification cost

Best baseline = minimum quality-equivalent available alternative

Compression Dividend = best-baseline lifecycle cost minus governed-state lifecycle cost

Negative results are valid.

Study parameters must not be tuned to force governed reuse to win.

## Economic Substitution Fraction

The substitution fraction s represents the fraction of fresh recomputation cost actually avoided by a successful governed-state hit.

It is not semantic similarity.

It is not token overlap.

It is not JSON field overlap.

It is a cost-weighted measure of avoided fresh computation.

## Failure Rules

Study 003 must stop economic comparison if:

- P1 fails the Quality Gate;
- P3 fails the Quality Gate;
- the selected public state surface proves internally ambiguous;
- the task changes after measurement begins;
- the reference changes after measurement begins;
- the evaluator changes after measurement begins;
- a required comparison path cannot be measured reliably.

A stopped or negative study remains a valid benchmark result.

## Scientific Boundary

Study 003 tests:

Can a fresh model reconstruct one explicitly selected independently public state surface, and can governed state retrieval satisfy that same state task at a lower requester cost?

Study 003 does not test whether a model can guess which of several public representations the benchmark author intended.
