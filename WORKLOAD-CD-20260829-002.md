# Compression Dividend Benchmark — Study 002

Study ID: CD-WORKLOAD-20260829-002

Status: DESIGN DRAFT — NO MEASUREMENTS

Study Type: Task-Equivalent Governed State Retrieval

Economic Perspective: Requesting AI / Agent

## Purpose

Study 002 tests whether governed state reuse can satisfy the exact same semantic task as fresh AI recomputation and, only after semantic equivalence is demonstrated, whether governed reuse produces a measurable economic Compression Dividend.

Study 002 is intentionally designed in response to Study 001.

Study 001 demonstrated that successful payment, HTTP 200, valid JSON, and related structured data are not sufficient to establish governed-state substitution. The paid Atomic Query returned a canonical identifier-resolution representation rather than the frozen Biography Plate state required by the task.

Study 002 therefore requires task equivalence before economic substitution is calculated.

## Primary Research Question

Can a governed retrieval endpoint return a frozen structured state that satisfies the same task contract as fresh AI recomputation?

If yes:

Does that governed retrieval reduce lifecycle cost relative to the best available quality-equivalent baseline?

## Paths

Path 1 — Fresh Recomputation

A model receives the frozen source facts and frozen task prompt and independently constructs the required structured response.

Path 2 — Provider Prompt Caching

The identical frozen task is executed using provider caching if caching is actually available for the workload.

Caching will not be manufactured by enlarging or altering the prompt solely to make caching activate.

Path 3 — Governed State Reuse

A governed retrieval endpoint returns a structured state intentionally designed to satisfy the exact same frozen task contract as Path 1.

## Central Study Rule

Economic comparison is permitted only between quality-equivalent outputs.

A Path 3 request is not a successful governed-state hit merely because:

- payment succeeds
- HTTP 200 is returned
- JSON is valid
- provenance exists
- the returned object is related to the target

Path 3 must satisfy the frozen Study 002 quality contract.

## Proposed Quality Contract

Contract ID: CD002-QC-1.0

Required fields:

- @context
- @type
- name
- description

Comparison rules:

- @context must exactly equal https://schema.org
- @type must exactly match the independent frozen reference
- name must exactly match the independent frozen reference
- description must exactly match the independent frozen reference
- extra fields may be permitted but ignored for pass/fail

- Unicode string values are compared exactly

## Economic Measurements

For quality-equivalent paths, measure:

Cre = measured fresh recomputation cost

C2 = measured provider-cached execution cost, if available

C3 = measured governed-state requester cost

Cb = minimum quality-equivalent available baseline cost

Incremental Compression Dividend = N × Cb − lifecycle governed-state cost

## Economic Substitution Fraction

For a successful Path 3 hit:

s = avoided fresh-recomputation cost / original fresh-recomputation cost

If Path 3 fully satisfies the frozen task with no residual model call:

s = 1

If residual model computation remains necessary:

s must be measured from paired governed and fresh-control observations.
