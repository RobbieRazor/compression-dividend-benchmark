Regime III Transition Surface

## Economic Perspective

Requesting AI or agent.

## Purpose

Study 004 locates the workload boundaries where Path 3 Governed State Reuse first becomes no more expensive than the cheapest actually available quality-equivalent baseline.

This boundary is Regime III — Best-Baseline Advantage.

Study 004 is a transition-location study. It is not designed to make Path 3 win.

## Study 003 Calibration Point

Study 003 established the following measured requester costs for one explicitly selected Biography Plate reconstruction task under the same frozen quality requirement:

- P1 fresh reconstruction: $0.00654020
- P2 provider cache hit: $0.00111572
- live P3 Structured Plate challenge: $0.25
- P3 divided by P2: approximately 224.070555
- P3 excess cost over P2: $0.24888428
- P3 semantic quality: NOT_MEASURED

Study 003 closed as:

NEGATIVE_INCREMENTAL_COMPRESSION_DIVIDEND_AT_LIVE_P3_PRICE

These values are bounded calibration evidence. They are not universal prices, costs, or performance claims.

## Primary Research Question

Under what combinations of governed acquisition price, reusable fan-out, lifecycle volume, baseline availability, governed hit rate, economic substitution fraction, verification cost, residual computation, preservation cost, maintenance cost, repair cost, miss overhead, fallback cost, and state lifetime does Path 3 satisfy:

LC3 less than or equal to LCbest

## Central Scientific Rule

A governed-state Compression Dividend exists only when Path 3:

1. satisfies the same semantic task as the competing paths;
2. satisfies the same explicitly selected representation;
3. passes the same preregistered Quality Gate;
4. is compared with every actually available quality-equivalent baseline; and
5. costs no more across the declared lifecycle than the cheapest of those baselines.

Transport success, payment success, valid JSON, governance metadata, provenance, or a related response do not independently establish successful economic substitution.

## Accepted Task Unit

One accepted task unit is one downstream task whose output passes the workload-specific frozen Quality Gate.

Costs associated with rejected outputs remain lifecycle costs but do not increase accepted-task volume.

N denotes accepted downstream task units over the declared lifecycle.

## Frozen Path Definitions

### Path 1 — Fresh Reconstruction

Path 1 independently reconstructs the required state for each accepted task without task-specific provider prompt-cache reuse or governed-state reuse.

Let:

C1 = measured requester cost per accepted fresh-reconstruction task

Then:

LC1(N) = N multiplied by C1

For the initial Study 003 anchor only:

C1 = $0.00654020

### Path 2 — Provider Prompt Caching

Path 2 uses provider-managed caching only when eligibility and actual cache behavior are empirically demonstrated for the exact workload.

Let:

- q2 = empirically supported P2 cache-hit probability over the declared lifecycle
- C2hit = requester cost of one accepted cache-hit task
- C2miss = requester cost of one accepted cache-miss or cache-write task
- W2 = total lifecycle cache warm-up, rewrite, or re-establishment cost not already included in C2miss

Then:

LC2(N) = W2 + N multiplied by the quantity q2 multiplied by C2hit plus the quantity one minus q2 multiplied by C2miss

P2 is excluded when it is unavailable or cannot satisfy the same Quality Gate.

For the initial optimistic Study 003 cache-hit anchor only:

- q2 = 1
- C2hit = $0.00111572
- W2 = 0 provisionally

This anchor reproduces the measured formal cache-hit comparison. It does not establish provider-cache persistence, cache lifetime, or a universal sustained hit rate.

### Best Available Baseline

Let E be the set of quality-equivalent baseline paths empirically available for the workload.

LCbest(N) = minimum lifecycle cost among all members of E

For a workload where only P1 and P2 qualify:

LCbest(N) = minimum of LC1(N) and LC2(N)

Baseline selection occurs from measured availability and accepted-task economics. It is not frozen in advance to favor Path 3.

### Path 3 — Governed State Reuse

Path 3 acquires and reuses a governed state that is eligible to satisfy some or all of the accepted downstream tasks.

Let:

- I3 = workload-attributable Path 3 setup cost
- P3a = governed acquisition price per state acquisition or refresh
- N = accepted downstream task volume
- Keff = effective accepted-task fan-out per acquired state
- A = required governed acquisition count
- F3 = total lifecycle preservation, storage, maintenance, and repair cost not included elsewhere
- h = probability that the acquired governed state is located, valid, accepted, and task-appropriate for a downstream task
- Cr = per-hit local retrieval or access cost
- Cv = per-hit verification and policy-validation cost
- Cres = per-hit residual computation cost required after reuse
- Cmiss = Path 3 miss-detection and routing overhead
- Cf = requester cost of the declared quality-equivalent fallback on a Path 3 miss

The acquisition count is:

A(N, Keff) = ceiling of N divided by Keff

The Path 3 hit cost is:

Chit = Cr + Cv + Cres

The Path 3 miss cost is:

Cmisspath = Cmiss + Cf

The frozen Path 3 lifecycle equation is:

LC3 = I3 + A multiplied by P3a + F3 + N multiplied by the quantity h multiplied by Chit plus the quantity one minus h multiplied by Cmisspath

No cost may be silently omitted because it is inconvenient, shared, small, or difficult to measure.

No cost may be counted twice.

## Effective Fan-Out and State Lifetime

Keff is not assumed to equal technical copy count.

Let:

- Ktechnical = maximum downstream accepted tasks technically serviceable from one acquisition
- Krights = maximum downstream accepted tasks permitted by the applicable rights and license
- Klifetime = maximum downstream accepted tasks completed before the state expires or requires refresh
- Kdemand = remaining downstream accepted-task demand

Then:

Keff = minimum of Ktechnical, Krights, Klifetime, and Kdemand

If task arrival rate is measured as lambda accepted tasks per unit time and state lifetime is T in the same time unit, then:

Klifetime = floor of lambda multiplied by T

If rights, lifetime, or technical reuse is unknown, Keff must not be assigned a value greater than one for a claimed empirical result.

The approximately 39-use and 225-use anchors are therefore conditional scenarios, not evidence that the current x402 license grants those fan-outs.

## Economic Substitution Fraction

Let:

Cre = measured fresh recomputation cost for the portion of work potentially replaced by a governed hit

s = economic substitution fraction, bounded from zero through one

For a controlled surface where residual computation is derived rather than separately observed:

Cres = the quantity one minus s multiplied by Cre

If Cres is directly measured, s must be derived from the same cost boundary:

s = one minus Cres divided by Cre

Study 004 must not independently choose both Cres and s for the same observation. One is an input and the other is derived.

s is not semantic similarity, token overlap, field overlap, graph similarity, or cache-hit percentage.

## Preservation, Maintenance, and Repair Boundary

F3 must include every workload-attributable lifecycle cost for:

- preservation and storage;
- refresh and synchronization;
- maintenance;
- validation-state renewal;
- repair after invalidation or drift; and
- any other required state stewardship not already included in acquisition, access, verification, residual computation, miss handling, or fallback.

General sunk platform-development expense is excluded unless Study 004 evaluates an implementation decision for which that cost is incremental and workload-attributable.

## Regime Classification

Regime I — Deficit:

LC3 is greater than LC1.

Regime II — Intermediate Advantage:

LC3 is less than or equal to LC1 and greater than LCbest.

Regime III — Best-Baseline Advantage:

LC3 is less than or equal to LCbest.

If P1 is already the best available baseline, Regime II may have zero width.

The Regime III transition surface is the equality boundary:

LC3 = LCbest

## Frozen Transition Equations

Define:

G = h multiplied by Chit plus the quantity one minus h multiplied by Cmisspath

Then:

LC3 = I3 + A multiplied by P3a + F3 + N multiplied by G

### Maximum Viable Governed Acquisition Price

For fixed N and A:

P3a maximum = the quantity LCbest minus I3 minus F3 minus N multiplied by G, divided by A

If this value is negative, no non-negative acquisition price can reach Regime III under the declared conditions.

### Minimum Reuse Fan-Out for One Acquisition Cycle

For a single state cycle serving K accepted tasks, with one acquisition, a per-task best-baseline cost Cbest, and a Path 3 marginal downstream cost G:

K minimum = ceiling of the quantity I3 plus P3a plus F3, divided by the quantity Cbest minus G

This threshold is finite only when Cbest is greater than G.

If Cbest is less than or equal to G, additional fan-out cannot amortize Path 3 into Regime III.

### Minimum Governed Hit Rate

Let:

H = Chit

M = Cmisspath

When H is less than M:

h minimum = the quantity I3 plus A multiplied by P3a plus F3 plus N multiplied by M minus LCbest, divided by N multiplied by the quantity M minus H

Interpretation:

- a result less than or equal to zero means all valid hit rates satisfy the economic threshold;
- a result between zero and one is the transition hit rate;
- a result greater than one means Regime III is infeasible through hit-rate improvement alone; and
- if H is greater than or equal to M, increasing h cannot lower lifecycle cost under the declared costs.

### Minimum Economic Substitution Fraction

When h is greater than zero and Cres is derived as the quantity one minus s multiplied by Cre:

s minimum = the quantity I3 plus A multiplied by P3a plus F3 plus N multiplied by the sum of h multiplied by the quantity Cr plus Cv plus Cre and the quantity one minus h multiplied by Cmisspath minus LCbest, divided by N multiplied by h multiplied by Cre

Interpretation:

- a result less than or equal to zero means zero substitution is already economically sufficient;
- a result between zero and one is the transition substitution fraction;
- a result greater than one means Regime III is infeasible through substitution improvement alone; and
- h equal to zero makes the substitution threshold undefined.

### Minimum Lifecycle Volume Under Stable Per-Task Conditions

When acquisition count A, fixed lifecycle costs, and per-task costs remain constant across the evaluated interval:

N minimum = ceiling of the quantity I3 plus A multiplied by P3a plus F3, divided by the quantity Cbest minus G

This threshold is finite only when Cbest is greater than G.

When A changes because another state acquisition or refresh becomes necessary, the threshold must be evaluated piecewise. A smooth amortization formula must not replace the ceiling-based acquisition count in the final empirical map.

## Quality and Availability Gates

An empirical point is eligible for the transition surface only when:

- every compared path passes the same preregistered Quality Gate;
- the target representation was selected before measurement;
- P2 availability and hit behavior were observed rather than assumed;
- P3 reuse rights and effective fan-out were established rather than inferred;
- verification and residual computation were measured or explicitly bounded;
- misses and fallbacks remain inside the lifecycle accounting boundary; and
- rejected tasks do not count as accepted-task fan-out.

## Failure and Censoring Rules

The result must be recorded as quality-censored rather than economically compared when a path fails semantic or representation equivalence.

The result must be recorded as availability-censored when an assumed path is not actually available.

The result must be recorded as rights-censored when reuse fan-out cannot be supported by the applicable rights.

The result must be recorded as measurement-incomplete when required costs cannot be measured or defensibly bounded.

Negative, infeasible, and censored results remain valid evidence.
