# Compression Dividend Benchmark — Study 008

Study ID: CD-WORKLOAD-20260831-008

## Purpose

Study 008 tests whether fresh model recomputation can exactly reconstruct a governed canonical graph when the public machine-readable authority boundary and the hidden evaluation target are independently frozen from the same contemporaneous governed state.

Studies 004 through 007 remain immutable and quality-censored. Their rejected observations are diagnostic evidence and are not accepted economic baselines.

Study 003 remains the most recent measured quality-equivalent economic anchor. Study 008 does not modify its result.

## Prospective Research Question

When a complete machine-readable authority surface and its hidden evaluation target are independently frozen from the same contemporaneous governed state, can fresh recomputation reconstruct that state exactly without seeing the protected target, target-construction mapping, Quality Contract, or evaluator?

## Preregistered Hypothesis

A model can satisfy the exact governed-state Quality Contract when every required canonical value and its relationship binding are explicitly present in a prospectively frozen, machine-readable authority boundary from which the hidden target is independently constructed.

## Preregistered Null Result

Even when the complete canonical state is explicitly available in a prospectively frozen authority boundary, fresh model recomputation does not preserve the exact governed graph under the frozen prompt and model boundary.

Either result is scientifically informative.

## Why This Study Is Prospective

Studies 004 through 007 evaluated reconstruction against a historical target whose exact values were not all explicitly published and bound within the available authority evidence.

Study 008 reverses the order:

1. Freeze the study design.

2. Freeze a nonpaying public-authority capture protocol.

3. Capture the contemporaneous authority once.

4. Verify and freeze the captured bytes and hashes.

5. Audit the authority for internal completeness and ambiguity.

6. Construct a new hidden target only from the frozen authority.

7. Freeze the target, Quality Contract, evaluator, and model-visible inputs.

8. Perform one preregistered P1 feasibility observation.

No historical hidden target governs Study 008.

## Authority Completeness Definition

The authority boundary is complete only if it explicitly and unambiguously supports a meaningful governed graph containing:

- subject identity

- canonical identifiers

- relationship labels

- exact relationship target values

- exact target-field placement

- entity types

- roles

- versions

- canonical URLs

- provenance bindings

- retrieval and usage rights

Every governed target leaf must have one deterministic governing source, an immutable source hash, a source location or extraction rule, and a canonical-selection rule.

Semantic implication, model inference, alternate ontology labels, paraphrases, shortened identifiers, values found only in non-governing locations, and invented completions do not establish authority completeness.

If multiple sources provide conflicting candidates and the frozen rules do not determine one governing value, the authority is ambiguous and completeness fails.

## Authority-Capture Boundary

The later capture protocol must be frozen, tested, secret-scanned, committed, and pushed before any live capture.

The protocol must:

- use public HTTPS only

- send no API key

- send no authorization header

- send no payment header

- follow no paid route

- refuse to overwrite an existing capture

- record timestamps, requested URLs, final URLs, HTTP statuses, content types, byte counts, and SHA-256 hashes

- fail closed on non-200 responses, unexpected content, redirects outside the approved boundary, or incomplete capture

- perform no model request

- perform no x402 payment

This design step does not select, call, or capture any live source.

## Completeness-Audit Boundary

The authority-completeness audit must occur after immutable capture and before target construction, model-input construction, or measurement.

The audit must determine whether the new authority is internally sufficient to define its own exact governed target. It must not compare the captured authority against the historical Study 005 through 007 hidden target.

If completeness or unambiguous canonical selection fails:

- stop Study 008 before target construction

- record authority-availability or authority-ambiguity censoring

- make no model request

- make no x402 payment

- do not repair or recapture production within Study 008

- preserve the negative authority-architecture result

## Independent Target-Construction Rules

If and only if the completeness audit passes, construct a new hidden target exclusively from the immutable contemporaneous authority capture.

Every target leaf must record:

- source artifact identifier

- source SHA-256

- source location or deterministic extraction rule

- canonical-selection rule

- explanation of why the selected source governs

A value may match an older target only when the same value independently appears in and is governed by the new frozen authority.

No value may be imported from the Study 005 through 007 target merely because it appeared in that historical target.

The completed target and its construction mapping must remain hidden from the measured model.
